Every service is a function exported by `@zeste/services`, named after its key. Its options are typed; the
required ones are marked. The catalog is generated from tarteaucitron.js. To add a missing service,
contribute it to [tarteaucitron.js](https://github.com/AmauriC/tarteaucitron.js), and zeste picks it up on its
next update.

```ts
import { gtag, youtube } from '@zeste/services';

const services = [gtag({ gtagUa: 'G-XXXXXXX' }), youtube()];
```

With the [script tag](../../start/script-tag/), use the key: `services: { gtag: { gtagUa: 'G-XXXXXXX' } }`.
