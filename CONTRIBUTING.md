# Contributing

Thanks for helping. Bug reports, fixes, new UI library variants and translations are all welcome.

## Setup

Node 24+ and pnpm 11 (`corepack enable` picks the right version).

```sh
pnpm install
pnpm typecheck
pnpm test                                        # unit tests
pnpm --filter e2e exec playwright install chromium   # once
pnpm --filter e2e test                           # builds every example, then runs Chromium tests
```

`pnpm --filter e2e exec playwright test --project=<name>` runs one project (`harness`, `sveltekit`, `skin-bits`…).
The `real-network` project loads real Google, YouTube and Matomo scripts: it depends on them, so CI runs it once a
week rather than on every push.

## Where things live

| Path | What |
|---|---|
| `packages/core` | Engine, cookie, plugins, compliance guard |
| `packages/services` | The catalog, **generated** from tarteaucitron.js |
| `packages/svelte`, `react`, `vue` | Framework bindings |
| `packages/browser` | The `<script>` version |
| `packages/cli` | `zeste init` and `zeste add`; the generated components are in `templates/` |
| `examples/` | Demo apps, also used by the e2e tests |
| `e2e/` | Playwright tests |
| `site/` | Website and docs (`pnpm --filter site dev`), English in `src/content/docs/docs`, French in `src/content/docs/fr/docs` |

## The service catalog

`packages/services/src` is generated by `pnpm --filter @zeste/services generate` from the `tarteaucitronjs`
package: do not edit it by hand. A missing or broken service is best fixed in
[tarteaucitron.js](https://github.com/AmauriC/tarteaucitron.js) and picked up here on the next update.

## Pull requests

- One topic per pull request, with a test: a unit test, or an e2e test when it is about what a browser loads.
- A change that loads anything earlier, or changes what is stored in the cookie, needs an e2e test proving that
  nothing reaches a third party before consent.
- A change to the public API comes with its documentation, in English and French.
- Code, comments and commit messages in English; commits follow [Conventional Commits](https://www.conventionalcommits.org)
  (`feat(core): …`, `fix(cli): …`).
