# zeste

The [zeste](https://anclavehq.github.io/zeste/) CLI.

```sh
npx zeste init   # finds the services the project already uses and declares them
npx zeste add    # copies a banner, preferences and placeholder written with your UI library
```

Ready-made for Svelte, React and Vue with Bits UI, Radix, Reka UI, Ark UI and shadcn.

[CLI reference](https://anclavehq.github.io/zeste/docs/reference/cli/) · MIT
