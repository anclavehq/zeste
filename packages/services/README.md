# @zeste/services

The [tarteaucitron.js](https://github.com/AmauriC/tarteaucitron.js) service catalog for
[zeste](https://anclavehq.github.io/zeste/): 247 services, one module per service with typed options, their code
downloaded only on consent, and the texts in 36 languages.

```ts
import { gtag, youtube } from '@zeste/services';
import { messages } from '@zeste/services/i18n/fr';
```
