# @zeste/react

React 18 and 19 bindings for [zeste](https://anclavehq.github.io/zeste/), headless cookie consent built on the
tarteaucitron.js catalog: `useZeste()`, `<ZesteProvider>`, `<ConsentBanner>`, `<ConsentGate>`, server rendering with
Next.js without a banner flash.

```sh
npm install @zeste/react @zeste/core @zeste/services
npx zeste add
```

[Get started with Next.js](https://anclavehq.github.io/zeste/docs/start/nextjs/) · MIT
