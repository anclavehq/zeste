# @zeste/svelte

Svelte 5 bindings for [zeste](https://anclavehq.github.io/zeste/), headless cookie consent built on the
tarteaucitron.js catalog: reactive state, `<ZesteProvider>`, `<ConsentBanner>`, `<ConsentGate>`, server rendering
without a banner flash.

```sh
npm install @zeste/svelte @zeste/core @zeste/services
npx zeste add
```

[Get started with SvelteKit](https://anclavehq.github.io/zeste/docs/start/sveltekit/) · MIT
