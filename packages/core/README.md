# @zeste/core

Framework-free cookie consent engine of [zeste](https://anclavehq.github.io/zeste/): consent state, a cookie
compatible with tarteaucitron.js, plugins (Google Consent Mode v2) and the compliance guard. Nothing is loaded
before consent.

```sh
npm install @zeste/core @zeste/services
```

Most projects use it through [@zeste/svelte](https://www.npmjs.com/package/@zeste/svelte),
[@zeste/react](https://www.npmjs.com/package/@zeste/react) or [@zeste/vue](https://www.npmjs.com/package/@zeste/vue).

[Documentation](https://anclavehq.github.io/zeste/docs/) · MIT
