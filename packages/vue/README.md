# @zeste/vue

Vue 3 bindings for [zeste](https://anclavehq.github.io/zeste/), headless cookie consent built on the
tarteaucitron.js catalog: reactive state, `<ZesteProvider>`, `<ConsentBanner>`, `<ConsentGate>`, server rendering
with Nuxt without a banner flash.

```sh
npm install @zeste/vue @zeste/core @zeste/services
npx zeste add
```

[Get started with Nuxt](https://anclavehq.github.io/zeste/docs/start/nuxt/) · MIT
